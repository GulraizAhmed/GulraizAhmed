# Sadia Ghafoor — Resume

Printable resume in HTML, PDF, and Word formats.

## Files

- `Sadia_Ghafoor_Resume.pdf` — ready-to-share PDF
- `Sadia_Ghafoor_Resume.docx` — editable Word document
- `index.html` — printable web version (source layout)
- `generate_docx.py` — regenerates the Word file from content

## Open / print

1. Open `Sadia_Ghafoor_Resume.pdf` or `Sadia_Ghafoor_Resume.docx` directly.
2. Or open `index.html` in a browser and use **Print → Save as PDF** (A4).
3. To regenerate Word after content edits: `python3 generate_docx.py`
